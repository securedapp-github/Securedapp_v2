# Completion report

Return this structure:

- **Outcome:** implemented, partial, blocked, or not started.
- **Changed files:** paths plus behavior.
- **Checks:** `PASS | FAIL | BLOCKED | NOT RUN` — exact command — evidence.
- **Review:** findings, fixes, or `none found` with checked areas.
- **Remaining risks:** concrete limitations and external blockers.
- **Deployment:** not performed unless explicitly authorized and verified.
- **Next step:** one safe follow-up.
