# Task packet

Use this compact contract when delegating work:

- **Objective:** one outcome, user-visible or operational.
- **Acceptance:** observable behavior and failure behavior.
- **Scope:** owned files/components; explicit exclusions.
- **Evidence:** relevant routes, callers, APIs, state, tests, and current status.
- **Constraints:** security, compatibility, performance, accessibility, deployment.
- **Validation:** exact checks required; expected evidence.
- **Blockers:** external access, credentials, production actions, or unresolved decisions.

Every packet must name one owner, avoid overlapping edits, and distinguish verified facts from assumptions.
