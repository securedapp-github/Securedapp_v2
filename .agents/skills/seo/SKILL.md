name: SEO
description: Audit and improve public-page metadata, canonical URLs, sitemap, robots, structured data, and crawl behavior.
---

Use only when the task concerns search visibility or public-page indexing.

Verify route inventory, title/description, canonical normalization, Open Graph, robots directives, sitemap URLs, redirects, and JSON-LD against visible page content. Keep noindex/private flows out of public indexes. Test rendered HTML, not only source files. Do not add generic schema or keyword stuffing. Preserve the project's Pages Router conventions.
