# Securedapp URL Branch

## Branch Information
- **Branch Name**: securedapp_url
- **Purpose**: Contains the complete Securedapp project with all source files, components, pages, and configurations
- **Creation Date**: April 29, 2026

## Project Structure
This branch contains:
- Complete Next.js application setup
- React components (products, services, blog, etc.)
- Page components and routing
- Redux state management
- Tailwind CSS styling
- TypeScript support
- Public assets (images, whitepaper, etc.)

## Key Files
- `package.json` - Project dependencies
- `tsconfig.json` - TypeScript configuration
- `next.config.mjs` - Next.js configuration
- `tailwind.config.js` - Tailwind CSS configuration
- `src/` - Main source directory with all components

## Features
- Multi-product SaaS platform
- Blog system with categorization
- Product showcases (Solidity Shield, Quantum Vault, SecureCMS, etc.)
- Service offerings (Smart Contract Audits, DeFi Development, etc.)
- AuditExpress tool integration
- Responsive design

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`
